# Ile_Cradle

Android-планетарий **Ile_Cradle** — интерактивная карта ночного неба.

## Возможности
- 88 ярких звёзд с реальными координатами RA/Dec J2000
- Расчёт горизонтальных координат (азимут/высота) для места и времени
- Тап по звезде → приближение и карточка объекта
- Анимация линий созвездия выбранной звезды
- Поиск, настройки, ночной красный режим
- GPS и ручной ввод координат
- Раздел туманностей (снимки NASA/ESA)

## Сборка
Actions → **Build Ile_Cradle** → Run workflow  
Скачай `Ile_Cradle-debug.apk` из артефакта.

Или локально: Android Studio + JDK 17 → `assembleDebug`.
